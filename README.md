# Tino

Presupuesto personal minimalista. Local-first, sin servicios pagos, sin cuentas.

## Funciones
- Ingresos, gastos, ahorro y asignaciones
- Cheques con plazos legales y alertas
- Calendario con integración a Google Calendar
- Metas, presupuestos y simulador de libertad financiera
- Modo discreto para usar en el trabajo
- 30+ temas (Boca, Matrix, Ghibli, Netflix…)
- Sincronización por archivo local o GitHub Gist
- Informes PDF con tipografía consola

## Uso

👉 **[Abrir Tino](https://fedecerelli.github.io/tino/)**

Los datos se guardan 100% en tu navegador. Nada viaja a ningún servidor.
